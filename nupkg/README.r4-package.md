# @PACKAGE@

ASP.NET Boilerplate 维护版组件。保留既有框架程序集和命名空间。

```sh
dotnet add package @PACKAGE@ --version 10.5.1
```

```powershell
Install-Package @PACKAGE@ -Version 10.5.1
```

包版本见 [@PACKAGE@](https://www.nuget.org/packages/@PACKAGE@/)。维护问题请提交到 [维护仓库](https://github.com/dusdong/aspnetboilerplate/issues)。
